# GarmentLove 

GarmentLove is a SaaS-based open-source point-of-sale and customer-relationship-manager system for laundry, laundromats, dry cleaning, and linen rental-based services. The user details items, tracks orders, assembles orders with items, and creates invoices. The user assigns customers to routes, creates appointments, creates orders from appointments, and delivers completed orders.

The customers sign up, create appointments, add items to processing orders, add addresses, update their profile, and check on their orders.
